# 二造 600 母题

2026 二级造价工程师《600母题》选择题练习。科目两门：土木建筑工程（土建）、建设工程造价管理（管理）。

上传文本型 PDF 后，服务端抽出单项选择题和多项选择题（题号、题干、选项、答案、解析），并写入本机 SQLite 数据库 `data/erzao.sqlite`。刷新、换浏览器都能看到同一份题库。服务端不建账号。

答错，或交卷时还没做的题，会进入错题库，并留下每次选择和时间。之后做对一次，就从错题库移出。每次点「交卷」会多一条历史记录，里面有得分和当时的错题。

## 本地运行

需要 Node.js 22.5 以上。启动脚本会打开 Node 自带的 SQLite。

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)。开发服务监听 `0.0.0.0:43123`。

请用 `localhost` 或 `127.0.0.1` 打开。如果改用别的主机名，需要把该主机名写进 `next.config.ts` 的 `allowedDevOrigins`，否则开发态页面会停在「正在打开本机数据库里的题库」。

把 PDF 拖进页面，并选好科目：

- `2026二造土建《600母题》.pdf`
- `2026二造管理《600母题》.pdf`

解析器按常见母题版式切题：题号、`A`–`E` 选项、`【答案】` / `答案：`、`【解析】` / `解析：`，以及题目在前、参考答案在后的分卷。对不上答案的题仍可做，提交后会写明「本题 PDF 中未识别到答案」。

```bash
npm test
npm run lint
```

## 解析做不到的事

- 扫描图片版 PDF 没有文字层，抽不出题。
- 选项不是 `A.` / `A、` 这类标记、或题号不在行首时，可能被跳过。
- 答案区没有题号、或单选多选答案混在一起且没有「单项 / 多项」标题时，个别题会对错答案。
- 解析里如果再嵌一套带选项的例题，可能被误认成新题。
